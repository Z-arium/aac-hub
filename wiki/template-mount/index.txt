Shows an in-game style tooltip for a mount, fetched from the sermeatball API. Hover over a skill name to read what it does.

'''Usage'''
<pre>{{Mount|9002335}}</pre>

* The only parameter is the item ID of the mount.
* The name, grade, description, skills (with effects) and move speed all come from the API. The icon is the game's own icon of the item (<code>icon_item_NNNN.png</code>, read from aa-classic.com); if that file is not on the wiki, the file named after the mount is used.
* speed (optional): replaces the move speed from the API, in m/s.
* float (optional): where the card sits on the page. <code>right</code> or <code>left</code> places it at that side with the text flowing around it, <code>center</code> centres it. Leave it out for a normal card in the flow of the page.

'''Examples'''
<pre>{{Mount|9002335|float=right}}
{{Mount|9002317|speed=11.7|float=left}}</pre>
* The data is read from data pages stored on the wiki (<code>Module:Data/Mounts/...</code>, made by <code>sync_wiki_data.py</code>), so the cards load without asking the APIs. A mount that is not stored yet is read live (cooldown, casting time and mana from aa-classic.com, one request per skill) until the script has been run for it.
* Needs <code>Module:Mount</code>, <code>Module:IconName</code>, <code>Template:Grade</code>, <code>Template:MountSkillRow</code> and <code>Template:Mount/styles.css</code>.

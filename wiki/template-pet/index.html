Template:Pet

Shows an in-game style tooltip for a pet (Pets, Powerstone Pets, Battle Pets). The skills in the description are hoverable and show their details, like the skills of mounts and gliders. Normally you use Template:Tooltip, which picks the right card for any item ID.

Usage 

{{Pet|56039}}
  • The only required parameter is the item ID of the pet (the item, not the NPC).
  • The data is read from data pages stored on the wiki (Module:Data/Pets/... and Module:Data/Skills/..., made by sync_wiki_data.py). A pet that is not stored yet is shown as a plain card (Template:Consumable, read live) without the skill boxes until the script has been run for it.
  • float (optional): right or left places the card at that side with the text flowing around it, center centres it.
  • use (optional): replaces the "Use:" text.
  • Needs Module:Pet, Module:Consumable, Module:Mount (for the hover box), Module:DataStore, Template:Consumable, Template:Consumable/styles.css and Template:Mount/styles.css.

Examples 

{{Pet|56039}}
{{Pet|8001817|float=right}}

No description.

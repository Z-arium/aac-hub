Shows an in-game style tooltip card for a skill: icon, skill line, name, element (top right), rank, mana, range, effect range, attack percent, cast time, cooldown, the effects it grants (buff icons), the description with the damage formula, combos and the chain the skill belongs to. This is a card you place on a page. The hover boxes of mount, glider and pet skills are separate and are not changed by this template.

'''Usage'''
<pre>{{Skill|36597}}</pre>

* The only required parameter is the skill ID (the number at the end of <code>https://aa-classic.com/database/skills/36597</code>). Skill IDs are not item IDs.
* The data is read from data pages stored on the wiki (<code>Module:Data/SkillCards/...</code>, made by <code>sync_wiki_data.py</code>). A skill that is not stored yet is read live from the API (without the effect icons) until the script has been run for it.
* Mana, range, effect range, cast time, cooldown, channeling time and labor cost are only shown when the data has them. The mana cost of many skills is calculated by the game and is 0 in the data, so no Mana line is shown then.
* Element (top right) and rank (after the name, <code>Triple Slash (Rank 1)</code>) come from the ancestral skill data. A skill that has ancestral variants shows Basic.
* Damage: the game's <code>#{avg_damage}</code> in the description is replaced by the formula of the data in green, for example <code>(260% Melee Attack)</code>, and the line <code>Melee Attack +260%</code> is shown under the ranges. The final damage is not calculated, because it depends on gear, level and conditions in the game.
* Combo: the sentences of the game with the icon of the condition and the result.
* Chain: skills that follow each other (Triple Slash) show all steps with the icons, the skill of the card is outlined. Clicking another icon switches the card to that skill, there is no need to put each skill on the page. The chain is found automatically from the data, and all skills of a chain are stored by <code>sync_wiki_data.py</code> when one of them is. The switching uses a link to the card (the address gets <code>#aa-skill1-36405</code> added) and CSS, so it also works for readers without scripts.
* All of this needs the skill to be stored (<code>sync_wiki_data.py</code>). A skill that is not stored yet is shown from the live API with the basic lines only.
* float (optional): <code>right</code> or <code>left</code> places the card at that side with the text flowing around it, <code>center</code> centres it.
* The icons need to be uploaded: <code>upload_icons_by_api.py --kind skills</code> and <code>--kind buffs</code> (effect and combo icons).
* Needs <code>Module:Skill</code>, <code>Module:Consumable</code>, <code>Module:IconName</code>, <code>Module:DataStore</code> and <code>Template:Skill/styles.css</code>.

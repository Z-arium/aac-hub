Template:Skill

Shows an in-game style tooltip card for a skill: icon, skill line, name, element (top right), rank, mana, range, effect range, attack percent, cast time, cooldown, the effects it grants (buff icons), the description with the damage formula, combos and the chain the skill belongs to. This is a card you place on a page. The hover boxes of mount, glider and pet skills are separate and are not changed by this template.

Usage 

{{Skill|36597}}
  • The only required parameter is the skill ID (the number at the end of https://aa-classic.com/database/skills/36597). Skill IDs are not item IDs.
  • The data is read from data pages stored on the wiki (Module:Data/SkillCards/..., made by sync_wiki_data.py). A skill that is not stored yet is read live from the API (without the effect icons) until the script has been run for it.
  • Mana, range, effect range, cast time, cooldown, channeling time and labor cost are only shown when the data has them. The mana cost of many skills is calculated by the game and is 0 in the data, so no Mana line is shown then.
  • Element (top right) and rank (after the name, Triple Slash (Rank 1)) come from the ancestral skill data. A skill that has ancestral variants shows Basic.
  • Damage: the game's #{avg_damage} in the description is replaced by the formula of the data in green, for example (260% Melee Attack), and the line Melee Attack +260% is shown under the ranges. The final damage is not calculated, because it depends on gear, level and conditions in the game.
  • Combo: the sentences of the game with the icon of the condition and the result.
  • Chain: skills that follow each other (Triple Slash) show all steps with the icons, the skill of the card is outlined. Clicking another icon switches the card to that skill, there is no need to put each skill on the page. The chain is found automatically from the data, and all skills of a chain are stored by sync_wiki_data.py when one of them is. The switching uses a link to the card (the address gets #aa-skill1-36405 added) and CSS, so it also works for readers without scripts.
  • All of this needs the skill to be stored (sync_wiki_data.py). A skill that is not stored yet is shown from the live API with the basic lines only.
  • float (optional): right or left places the card at that side with the text flowing around it, center centres it.
  • The icons need to be uploaded: upload_icons_by_api.py --kind skills and --kind buffs (effect and combo icons).
  • Needs Module:Skill, Module:Consumable, Module:IconName, Module:DataStore and Template:Skill/styles.css.

Examples

{{Skill|36597|float=right}}

No description.

<h2 id="Installing_Addons">Installing Addons</h2>
<h3 id="Recommended:_Addon_Manager">Recommended: Addon Manager</h3>
<p>The best way to install addons is to use the Addon Manager created by Sami.
</p><p>You can download it on Github here: <a rel="noopener" href="https://github.com/classic-addon-manager/classic-addon-manager/releases">https://github.com/classic-addon-manager/classic-addon-manager/releases</a>
</p><p>By downloading "classic-addon-manager.exe". When you open it, you'll be able to browse addons and install them at the click of a button!
</p>
<h3 id="Installing_manually">Installing manually</h3>
<p>You can also install addons manually by downloading the source code of an addon. You can then extract the source code into a folder located in Documents/AAClassic/Addon/...
</p><p>Then, in your addons.txt file, write the name of the folder so that the game knows about it!
</p>
<h2 id="Creating_Addons">Creating Addons</h2>
<p>More documentation will be given soon about how to create your own addons. In the meantime, check on Discord as some examples are there!
</p><p>You can also read the <a href="/aac-hub/wiki/addon-api">Addon API</a>

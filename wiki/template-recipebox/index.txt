Shows a craft recipe, fetched from the sermeatball crafting API. The recipe row shows how many items one craft makes. When the craft has a bonus rate above 100 (and below 1000, since 10000 is not a percentage), a "Chance for 2x" row shows the extra percentage. Workbench, proficiency and materials come from the API. Coins in the recipe are shown last in the Materials list. A Recipe Cost row shows the total price of the materials, and is left out when the API has no price for them. Both as Gold / Silver / Copper.

'''Usage'''
<pre>{{RecipeBox|9001323}}</pre>

* The craft ID is the only required parameter.
* The recipe is read from a data page stored on the wiki (<code>Module:Data/Recipes/...</code>, made by <code>sync_wiki_data.py</code>). Only the Recipe Cost is fetched live, it follows the market. A recipe that is not stored yet is read live from the API until the script has been run for it. After a recipe changes in the game, run the script with <code>--recipe ID --refresh</code>.
* float (optional): where the box sits on the page. <code>right</code> or <code>left</code> places it at that side with the text flowing around it, <code>center</code> centres it. Leave it out for a normal box in the flow of the page.
'''Examples'''
<pre>{{RecipeBox|9001323|float=right}}
{{RecipeBox|9001323|float=left}}</pre>

* Needs the templates <code>RecipeMaterialLine</code>, <code>Coins</code> and <code>Item</code>, and the style page <code>Template:RecipeBox/styles.css</code>.
* On narrow screens (phones) a floated box gets its own line instead of squeezing the text.

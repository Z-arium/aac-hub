Settings

The Settings menu allows players to customize various aspects of ArcheAge Classic, including the user interface, graphics, controls, and gameplay options. Make sure you check out the "ArcheAge Classic" section in your Settings menu as there are plenty of custom settings for you to discover in there.

Themes

ArcheAge Classic offers three widely different UI themes which you can find at the bottom of your settings menu under "ArcheAge Classic" -> "Misc. Settings" -> "UI Customization".

  • Classic - This is the regular light ArcheAge UI theme that we are all familiar with.
  • ArcheWorld - This is a much darker theme, containing a lot of dark blues and blacks. This theme is available to everyone.
  • Classic Dark (Premium) - This is your typical dark theme containing mostly shades of greys and blacks which are very easy on the eyes. To select this theme you need to have the Daru Blessing active.

Name Colors

If you navigate to Settings -> ArcheAge Classic -> Screen Options -> Nametag Color Settings you can change the colors of any of the names and HP bars you can see.

These settings gives you a lot of freedom to alter the way you view other players and NPCs at a glance and can help you identify things much faster, for example if someone in your party/raid is Bloodlusted you can have their color set to a much more "friendly" color than what Bloodlusted players outside of your party/raid have. This lets you distinguish between friend and foe very easily.

Ultra Mode

ArcheAge Classic has custom Ultra graphics options that improves the look of the game immensely, they increase your view distance, increase your texture resolutions and more. The game looks very pretty with them turned on and don't result in a massive drop in framerate. The main issue comes with the increased amount of crashes these settings bring, therefore it is recommended to only use these settings when taking screenshots or making cinematic videos/clips.

Tricking the Game Into Saving Your Settings

It is most commonly known that any settings you change during your current session will go lost if you were to crash. This is because the game doesn't properly save your settings until exitting the game.

The point at which the game saves the settings is actually right after you press "Exit Game" so by cancelling the countdown you have effectively protected your new settings from being lost through a crash without actually closing the game.

Troubleshooting

New Install (Save Settings Crash Issue)

If you just installed the game you want to make sure that you open the settings in Server Select or Character Select and press Apply before continuing. This is because if you were to try and start changing settings in-game without doing this at least once then the game will crash.

UI Size Setting (Crashing Issue)

The UI Size setting controls the size of the ArcheAge Classic user interface.

This setting has been modified to allow for increasing your UI size to up to 160% which is quite "big" news for players using 4K monitors and the likes. There is one caveat to this setting after being modified and that is that you have to be in either Server Select of Character Select in order to change it. Any attempt in changing it in-game will result in a crash.

Settings Don't Save No Matter What

Some players may experience an issue where their settings revert to default values after restarting the game even if saving them properly.

Possible Causes

The game stores settings locally on the player's computer. If the game is unable to properly write to its configuration files, changes may not be saved.

  1. The most common fix to this issue is to navigate to C:\Users\YOUR USER\Documents\ and renaming the AAClassic folder found there to something like AAClassicOLD. The next time you start ArcheAge the AAClassic folder in your Documents folder will regenerate and in most cases this will fix your resetting settings issue.
  2. If however this did not fix your issue then you most likely have a program that interferes with the Documents folder, typically OneDrive is one such program that has a tendency of breaking the AAClassic folder within the Documents folder. This is because OneDrive specifically syncs everything in your Documents and likely impacts the game's ability to read/write within it. Turning off the Sync and/or OneDrive should fix the issue, you might need to regenerate the AAClassic folder like in the previous paragraph in order for it to start acting normal again.

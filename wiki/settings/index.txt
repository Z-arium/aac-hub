<h2 id="Ultra_Mode">Ultra Mode</h2>
<p>ArcheAge Classic has custom Ultra graphics options that improves the look of the game immensely, they increase your view distance, increase your texture resolutions and more. The game looks very pretty with them turned on and don't result in a massive drop in framerate. The main issue comes with the increased amount of crashes these settings bring, therefore it is recommended to only use these settings when taking screenshots or making cinematic videos/clips. 
</p>
<h2 id="Tricking_the_Game_Into_Saving_Your_Settings">Tricking the Game Into Saving Your Settings</h2>
<figure><img src="/aac-hub/wiki-files/eb/eb280fddcc748841b9debd15d59bf0c9563a5ca3.png" width="300" height="165" loading="lazy"><figcaption>After pressing "Exit Game" your settings are saved, just cancel the countdown. </figcaption></figure>
<p>It is most commonly known that any settings you change during your current session will go lost if you were to crash. This is because the game doesn't properly save your settings until exitting the game. 
</p><p>The point at which the game saves the settings is actually right after you press "Exit Game" so by cancelling the countdown you have effectively protected your new settings from being lost through a crash without actually closing the game.  
</p>
<h2 id="Troubleshooting">Troubleshooting</h2>
<h3 id="New_Install_(Save_Settings_Crash_Issue)"><span></span>New Install (Save Settings Crash Issue)</h3>
<p>If you just installed the game you want to make sure that you open the settings in Server Select or Character Select and press Apply before continuing. This is because if you were to try and start changing settings in-game without doing this at least once then the game will crash. 
</p>
<h3 id="UI_Size_Setting_(Crashing_Issue)"><span></span>UI Size Setting (Crashing Issue)</h3>
<p>The <b>UI Size</b> setting controls the size of the ArcheAge Classic user interface.
</p><p>This setting has been modified to allow for increasing your UI size to up to 160% which is quite "big" news for players using 4K monitors and the likes. There is one caveat to this setting after being modified and that is that you have to be in either Server Select of Character Select in order to change it. Any attempt in changing it in-game will result in a crash.

<h3 id="Settings_Don't_Save_No_Matter_What"><span></span>Settings Don't Save No Matter What</h3>
<p>Some players may experience an issue where their settings revert to default values after restarting the game even if saving them properly. 
</p>
<h4 id="Possible_Causes">Possible Causes</h4>
<p>The game stores settings locally on the player's computer. If the game is unable to properly write to its configuration files, changes may not be saved.
</p>

== Tricking the Game Into Saving Your Settings ==
[[File:ArcheAge Exit Game Menu.png|thumb|right|After pressing "Exit Game" your settings are saved, just cancel the countdown. ]]
It is most commonly known that any settings you change during your current session will go lost if you were to crash. This is because the game doesn't properly save your settings until exitting the game. 

The point at which the game saves the settings is actually right after you press "Exit Game" so by cancelling the countdown you have effectively protected your new settings from being lost through a crash without actually closing the game.  

== Troubleshooting ==

=== New Install (Save Settings Crash Issue) ===
If you just installed the game you want to make sure that you open the settings in Server Select or Character Select and press Apply before continuing. This is because if you were to try and start changing settings in-game without doing this at least once then the game will crash. 

=== UI Size Setting (Crashing Issue) ===
The '''UI Size''' setting controls the size of the ArcheAge Classic user interface.

This setting has been modified to allow for increasing your UI size to up to 160% which is quite "big" news for players using 4K monitors and the likes. There is one caveat to this setting after being modified and that is that you have to be in either Server Select of Character Select in order to change it. Any attempt in changing it in-game will result in a crash.

Some players may experience an issue where their settings revert to default values after restarting the game even if saving them properly.

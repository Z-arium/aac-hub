Shows the in-game style tooltip card of any item. The template finds out what kind of item it is from the item ID and uses the right card: [[Template:Mount]] for mounts, [[Template:Glider]] for gliders and Magithopters, and [[Template:Consumable]] for everything else (potions, food, talismans, tokens, crates ...).

'''Usage'''
<pre>{{Tooltip|9002466}}</pre>

* The only required parameter is the item ID.
* The kind of item is read from the data stored by <code>sync_wiki_data.py</code> (<code>Module:Data/Cards/...</code>). An ID that is not stored yet is looked up live (one request to the API) until the script has been run.
* float (optional): <code>right</code>, <code>left</code> or <code>center</code>, passed on to the card.
* speed (optional): only used by mounts, replaces the speed from the API.
* use (optional): replaces the "Use:" text of the card (gliders and consumables).
* A new card type is added in <code>Module:Tooltip</code>: one line in the table REGISTRY (category of the item → template).
* Needs <code>Module:Tooltip</code>, <code>Module:DataStore</code> and the card templates.

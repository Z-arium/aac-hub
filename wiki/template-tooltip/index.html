Template:Tooltip

Shows the in-game style tooltip card of any item. The template finds out what kind of item it is from the item ID and uses the right card: Template:Mount for mounts, Template:Glider for gliders and Magithopters, and Template:Consumable for everything else (potions, food, talismans, tokens, crates ...).

Usage 

{{Tooltip|9002466}}
  • The only required parameter is the item ID.
  • The kind of item is read from the data stored by sync_wiki_data.py (Module:Data/Cards/...). An ID that is not stored yet is looked up live (one request to the API) until the script has been run.
  • float (optional): right, left or center, passed on to the card.
  • speed (optional): only used by mounts, replaces the speed from the API.
  • use (optional): replaces the "Use:" text of the card (gliders and consumables).
  • A new card type is added in Module:Tooltip: one line in the table REGISTRY (category of the item → template).
  • Needs Module:Tooltip, Module:DataStore and the card templates.

Examples

{{Tooltip|8001101|float=right}}

Shows an in-game style tooltip for a glider, fetched from the sermeatball API.

'''Usage'''
<pre>{{Glider|8001101}}</pre>

* The only required parameter is the item ID of the glider.
* The data is read from data pages stored on the wiki (<code>Module:Data/Gliders/...</code>, made by <code>sync_wiki_data.py</code>). A glider that is not stored yet is read live from the API until the script has been run for it.
* The icon is the game's own icon of the glider (from the glider API); if that file is not on the wiki, the file named after the glider is used.
* The name, description and the flight stats (speed, gliding, turning, launch height, special skills) come from the API, with the colours of the game.
* float (optional): where the card sits on the page. <code>right</code> or <code>left</code> places it at that side with the text flowing around it, <code>center</code> centres it. Leave it out for a normal card in the flow of the page.
* Each special skill gets its own row, and is hoverable. The skill IDs come from the glider part of the API (<code>/wiki/glider/&lt;id&gt;</code>), matched by skill name. A skill the API does not list is shown as coloured text. <code>Module:GliderSkillIds</code> is optional now: an ID written there is only used for a skill the API did not give.
* use (optional): replaces the "Use:" text. Normally the standard glider text is used, and Magithopters (descriptions with "Air Speed") get the Magithopter text.
* The "Equip effect" text is written in the module.
* Needs <code>Module:Glider</code>, <code>Module:IconName</code>, <code>Template:Grade</code>, <code>Template:GliderSkillRow</code>, <code>Template:GliderSkill</code> (and through it <code>Module:Mount</code> and <code>Template:Mount/styles.css</code>) and <code>Template:Glider/styles.css</code>.

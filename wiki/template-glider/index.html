Template:Glider

Shows an in-game style tooltip for a glider, fetched from the sermeatball API.

Usage 

{{Glider|8001101}}
  • The only required parameter is the item ID of the glider.
  • The data is read from data pages stored on the wiki (Module:Data/Gliders/..., made by sync_wiki_data.py). A glider that is not stored yet is read live from the API until the script has been run for it.
  • The icon is the game's own icon of the glider (from the glider API); if that file is not on the wiki, the file named after the glider is used.
  • The name, description and the flight stats (speed, gliding, turning, launch height, special skills) come from the API, with the colours of the game.
  • float (optional): where the card sits on the page. right or left places it at that side with the text flowing around it, center centres it. Leave it out for a normal card in the flow of the page.
  • Each special skill gets its own row, and is hoverable. The skill IDs come from the glider part of the API (/wiki/glider/<id>), matched by skill name. A skill the API does not list is shown as coloured text. Module:GliderSkillIds is optional now: an ID written there is only used for a skill the API did not give.
  • use (optional): replaces the "Use:" text. Normally the standard glider text is used, and Magithopters (descriptions with "Air Speed") get the Magithopter text.
  • The "Equip effect" text is written in the module.
  • Needs Module:Glider, Module:IconName, Template:Grade, Template:GliderSkillRow, Template:GliderSkill (and through it Module:Mount and Template:Mount/styles.css) and Template:Glider/styles.css.

Examples 

{{Glider|8001101}}
{{Glider|8001101|float=right}}

No description.

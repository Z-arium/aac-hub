Patch 1.3.1.1

Released on 31/10/24

  • Some event messages that were in Korean have been translated back to English
  • The Pure Ice Packs tradepack can be stored again
  • Serendipity Stones will no longer be titled "Bound Serendipity Stone"
  • The Infused Emerald for the Emerald Hasla weapons will now be bound
  • Hellkissed Evenstones should now allow for the destruction of the Hellkissed weapons again
  • Flame Endless Arrows should now work correctly with Serpent's Sight
  • The values of Sunken Treasure have been adjusted
  • The chests from the Castaway Treasure Chests event will be spawning! They count as RELIC PACKS and must be turned in to any RELIC trader!
  • The Mysterious Crates found in Auroria have been fixed and its value increased to 500 gold per pack
  • The Salvage Forges will no longer offer converting back into TSTs
  • The changes to Saplings, Seeds and Livestock prices have been restored back to their pre-1.3 values. Farmers rejoice!
  • Some union busting work has been done to make gold traders from 3.0 get back to work
  • Fixed vehicle upgrade tickets being convertible and their crafting recipes.
  • Fixed the category for Seastorm Prototype craft
  • Hallowtide crafting recipes have all been changed to a single token. Existing tokens will convert to a primary token to be used for the entire event.
  • Fixed localization errors with regrade charms
  • Updated "The Spirit of Halloween" to be a daily quest. More Jack-o-snacks for everyone!

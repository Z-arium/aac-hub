Server Updates/Patch 1.1.3 - Castle and Item Adjustments

Item Changes

  • Charcoal Stabilizers and Fabric now stack up to 1000
  • Royal Seeds should now have the chance to drop from bundles

Crafting Changes

  • The level requirement for crafting Tax Certificates has been increased to level 50

Castle Changes

  • The Lord‘s Coin cost of construction materials has been halved
    • Luxury Territory Pack was reduced to 50 Lord‘s Coins, not 45
    • advanced and Basic remain at 45 Lord‘s Coins per

Other

  • Costumes have been fixed and some costumes have been made dyable

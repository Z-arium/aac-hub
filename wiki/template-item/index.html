Template:Item

File:(((1))).png {{{1}}} Shows an item with its icon (with the grade border), its name in the grade colour and an optional amount.

Usage by item ID The name, grade and icon all come from the game data, so the item ID is all you need. 

{{Item|ItemID=135135|500}}      the item with ID 135135, amount 500
{{Item|ItemID=135135}}          no amount
  • ItemID (also written id): the item ID, for example from https://aa-classic.com/database/items
  • The first unnamed value is then the amount (or write amount=500).
  • grade (optional): overrides the item's own grade, for example the grade a recipe asks for.
  • The data comes from the data pages on the wiki (made by sync_wiki_data.py), so no request is needed. An item that is not stored yet is fetched live (two requests) until the script has been run for it.
  • If the data cannot be found at all, nothing is shown (an invisible comment is left in the page source).

Usage by item name 

{{Item|Hay Bale|Basic|3}}      name, grade, amount (the icon is the file named after the item)
  • icon (optional): the game's own icon file name, for example icon_item_3400.png, used by the automatic templates.

Needs Module:IconName and Template:Grade; the ID form also needs External Data.

No description.

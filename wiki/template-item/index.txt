Shows an item with its icon (with the grade border), its name in the grade colour and an optional amount.

'''Usage by item ID'''
The name, grade and icon all come from the game data, so the item ID is all you need.

* ItemID (also written <code>id</code>): the item ID, for example from https://aa-classic.com/database/items
* The first unnamed value is then the amount (or write <code>amount=500</code>).
* grade (optional): overrides the item's own grade, for example the grade a recipe asks for.
* The data comes from the data pages on the wiki (made by sync_wiki_data.py), so no request is needed. An item that is not stored yet is fetched live (two requests) until the script has been run for it.
* If the data cannot be found at all, nothing is shown (an invisible comment is left in the page source).

'''Usage by item name'''
<pre>{{Item|Hay Bale|Basic|3}}      name, grade, amount (the icon is the file named after the item)</pre>
* icon (optional): the game's own icon file name, for example <code>icon_item_3400.png</code>, used by the automatic templates.

Needs <code>Module:IconName</code> and <code>Template:Grade</code>; the ID form also needs External Data.

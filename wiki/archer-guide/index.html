Archer Guide

Archer classes specialize in ranged combat and DPS.

Skill Trees

Generally, there is a primary set of skill trees for each main tree (Battlerage, Sorcery, Archer, Vitalism) that has variations by swapping one or both of the other trees for specific purposes. The first class in the list below is generally considered the primary set of skill trees..

  • Primeval (Archery, Shadowplay, Auramancy)
    • Well rounded, DPS focused archer class.
  • Ebonsong (Archery, Songcraft, Shadowplay)
    • More burst focused archer class based around zeal (songcraft passive).
  • Stonearrow (Archery, Shadowplay, Defense)
    • Sacrifices some DPS and mobility for additional tankiness..
  • Bastion (Archery, Defense, Auramancy)
    • Sacrifices some DPS and mobility for additional tankiness.

Gearing

The following links are baseline sets and may not reflect your ideal gear set. Additionally, the grade of your gear doesn't need to match exactly. For example, you could have the whole set at celestial grade, prior to upgrading to divine.

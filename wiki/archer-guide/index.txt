<h3 id="Skill_Trees">Skill Trees</h3>
<p><i>Generally, there is a primary set of <a href="/aac-hub/wiki/skill-trees">skill trees</a> for each main tree (Battlerage, Sorcery, Archer, Vitalism) that has variations by swapping one or both of the other trees for specific purposes. The first class in the list below is generally considered the primary set of skill trees..</i>
</p>
<ul><li>Primeval (Archery, Shadowplay, Auramancy)
<ul><li>Well rounded, DPS focused archer class.</li></ul></li>
<li>Ebonsong (Archery, Songcraft, Shadowplay)
<ul><li>More burst focused archer class based around zeal (songcraft passive).</li></ul></li>
<li>Stonearrow (Archery, Shadowplay, Defense)
<ul><li>Sacrifices some DPS and mobility for additional tankiness..</li></ul></li>
<li>Bastion (Archery, Defense, Auramancy)
<ul><li>Sacrifices some DPS and mobility for additional tankiness.</li></ul></li></ul>

Daru Subscription Box

The Daru Subscription Box is a monthly box that can be obtained for 1000 credits in the marketplace. This box is purely "Pay for Convenience" containing no items that provide any true advantage for players.

Daru Subscription Box contents:

  • (30 Day) Any-Post Owl, Summons Owl Mailbox
  • (30 Day) Anywhere Warehouse, Summons a warehouse manager
  • (30 Day Buff) Blessing from the Darus
    • -50% Portal Cast Time
    • -50% Embers Cast Time
    • -50% Recall Cast Time
    • +10,000 For all Language Proficiencies
    • Shorter "Good Night's Sleep" duration
    • Auction House listings show Seller's name
    • Can summon Lanayu, Blessed Frog
  • x1 Golden Token, These can be redeemed on the marketplace Award > Golden Token.

Using Your Golden Tokens

Golden tokens can be spent in the Marketplace, simply load the Marketplace, select the "Award" tab, followed by "Golden Token"

Template:Consumable

Shows an in-game style tooltip for an item that is used or opened: potions, food, talismans, tokens, crates and so on. It is also the card for every item that has no card of its own. Normally you use Template:Tooltip, which picks the right card for any item ID.

Usage 

{{Consumable|9002463}}
  • The only required parameter is the item ID.
  • The data is read from data pages stored on the wiki (Module:Data/Cards/..., made by sync_wiki_data.py). An item that is not stored yet is read live from the APIs until the script has been run for it.
  • The card shows the category (Potion, Food, Token ...), the grade, the name, "Untradeable" for bound items, the description, the "Use:" effect and "Cannot Sell", with the colours of the game.
  • float (optional): right or left places the card at that side with the text flowing around it, center centres it.
  • use (optional): replaces the "Use:" text.
  • untradeable (optional): no hides the "Untradeable" line (the pet card uses this when it falls back to this card).
  • cannotsell (optional): no hides the "Cannot Sell" line (also used by the pet card's fallback).
  • Needs Module:Consumable, Module:IconName, Module:DataStore, Template:Grade and Template:Consumable/styles.css.

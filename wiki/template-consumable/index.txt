Shows an in-game style tooltip for an item that is used or opened: potions, food, talismans, tokens, crates and so on. It is also the card for every item that has no card of its own. Normally you use [[Template:Tooltip]], which picks the right card for any item ID.

'''Usage'''
<pre>{{Consumable|9002463}}</pre>

* The only required parameter is the item ID.
* The data is read from data pages stored on the wiki (<code>Module:Data/Cards/...</code>, made by <code>sync_wiki_data.py</code>). An item that is not stored yet is read live from the APIs until the script has been run for it.
* The card shows the category (Potion, Food, Token ...), the grade, the name, "Untradeable" for bound items, the description, the "Use:" effect and "Cannot Sell", with the colours of the game.
* float (optional): <code>right</code> or <code>left</code> places the card at that side with the text flowing around it, <code>center</code> centres it.
* use (optional): replaces the "Use:" text.
* untradeable (optional): <code>no</code> hides the "Untradeable" line (the pet card uses this when it falls back to this card).
* cannotsell (optional): <code>no</code> hides the "Cannot Sell" line (also used by the pet card's fallback).
* Needs <code>Module:Consumable</code>, <code>Module:IconName</code>, <code>Module:DataStore</code>, <code>Template:Grade</code> and <code>Template:Consumable/styles.css</code>.

12:T9500,<h2 id="A_Page_dedicated_to_Wiki_Editors">A Page dedicated to Wiki Editors</h2>
<p>Sheoix made alot of new Templates and Tables for us to use and this is a quick explanation of all new functions to it.
</p>
<h3 id="How_to_add_Mounts">How to add Mounts</h3>
<p>To add a mount you can simply use <code>Insert &gt; Template</code> and search for <u>Mount</u>. 
</p><p>To add a new mount, simple grab its ID from the <a rel="noopener" href="https://aa-classic.com/database/item">AA Classic Database</a> and paste it into field called Item ID. As an addition you can also add a custom Mount Speed and the position of the Mount Box by selecting both on the left side of the Template.
</p>

<h3 id="How_to_add_Recipe_Boxes">How to add Recipe Boxes</h3>
<p>To add a recipe box you can simply use <code>Insert &gt; Template</code> and search for <u>RecipeBox</u>.
</p><p>To add a new recipe, simple grab its ID from the <a rel="noopener" href="https://aa-classic.com/database/crafts">AA Classic Database</a> and paste it into field called Craft ID. As an addition you can also set the position of the Recipe Box by selecting it on the left side of the Template.
</p>

<h3 id="How_to_write_in_Grade_Colors">How to write in Grade Colors</h3>

<h3 id="How_to_add_an_Item">How to add an Item</h3>
<p>To write in an item to your text with a grade to it such as <span style="width:32px; vertical-align:middle"><span><span><img src="/aac-hub/wiki-files/1f/1f2a2603ea656d53f0f87c7ceba22a02eeaa3996.png" width="32" height="32" loading="lazy"></span></span><span><span><span><img src="/aac-hub/wiki-files/7b/7bd27f9fa477796629bc90db3ce728abab64aade.png" width="32" height="32" loading="lazy"></span></span></span></span> <span style="color: rgb(201, 11, 11)">Hay Bale</span>&#160;× 50, you can simply use <code>Insert &gt; Template</code> and search for <u>Item</u>.
</p><p>To choose an item simply select the desired item in the dropdown, select your grade in the dropdown below that and as an extra option, you can choose a quantity for it by selecting the setting in the left side of the template and typing the desired number into the input field. (Currently Only Hay Bales exist, more tba in future).

16:T1cdb,== A Page dedicated to Wiki Editors ==
Sheoix made alot of new Templates and Tables for us to use and this is a quick explanation of all new functions to it.

=== How to add Mounts ===
To add a mount you can simply use <code>Insert > Template</code> and search for <u>Mount</u>. 

To add a new mount, simple grab its ID from the [https://aa-classic.com/database/item AA Classic Database] and paste it into field called Item ID. As an addition you can also add a custom Mount Speed and the position of the Mount Box by selecting both on the left side of the Template.

  <div style="float: left; margin-right: 20px; margin-bottom: 20px;">
    [[File:Choose mount template.png|frameless|453x453px]]
  </div>
  <div style="float: left; margin-bottom: 20px; text-align: left;">
    [[File:Mount input itemID.png|frameless|486x486px]]
    <br><br>
    [[File:Mount template settings.png|frameless|482x482px]]
  </div>
</div>
<div style="clear: both; height: 1px;"></div>
In case you should prefer Source editing, just use <code><nowiki>{{Mount|<MountID>|speed=<Mount Speed>|float=<right/left/center>}}</nowiki></code>. The follwing example was made using this Source Edit: <code><nowiki>{{Mount|51188|speed=15.8|float=center}}</nowiki></code>.

{{Mount|51188|speed=15.8|float=center}}

You can also put multiple of those next to each other, displaying multiple mounts like this, but it looks weird on mobiles or smaller screens, since one is aligned to the left, one to the right and one to the center.

=== How to add Recipe Boxes ===
To add a recipe box you can simply use <code>Insert > Template</code> and search for <u>RecipeBox</u>.

To add a new recipe, simple grab its ID from the [https://aa-classic.com/database/crafts AA Classic Database] and paste it into field called Craft ID. As an addition you can also set the position of the Recipe Box by selecting it on the left side of the Template.

=== How to write in Grade Colors ===
To write in an item grade color such as {{Grade|Mythic|Mythic}}, you can simply use <code>Insert > Template</code> and search for <u>Grade</u>.

To choose a color simply select the desired grade in the dropdown and input your text in the box below that.

=== How to add an Item ===
To write in an item to your text with a grade to it such as {{Item|Hay Bale|Mythic|50}}, you can simply use <code>Insert > Template</code> and search for <u>Item</u>.

To choose an item simply select the desired item in the dropdown, select your grade in the dropdown below that and as an extra option, you can choose a quantity for it by selecting the setting in the left side of the template and typing the desired number into the input field. (Currently Only Hay Bales exist, more tba in future).

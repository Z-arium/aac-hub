How to add Mounts

To add a mount you can simply use Insert > Template and search for Mount.

To add a new mount, simple grab its ID from the AA Classic Database and paste it into field called Item ID. As an addition you can also add a custom Mount Speed and the position of the Mount Box by selecting both on the left side of the Template.

In case you should prefer Source editing, just use {{Mount|<MountID>|speed=<Mount Speed>|float=<right/left/center>}}. The follwing example was made using this Source Edit: {{Mount|51188|speed=15.8|float=center}}.

How to add Recipe Boxes

To add a recipe box you can simply use Insert > Template and search for RecipeBox.

To add a new recipe, simple grab its ID from the AA Classic Database and paste it into field called Craft ID. As an addition you can also set the position of the Recipe Box by selecting it on the left side of the Template.

In case you should prefer Source editing, just use {{RecipeBox|<RecipeID>|float=<right/left/center>}}. The follwing example was made using this Source Edit: {{RecipeBox|7136|float=center}}.

How to write in Grade Colors

To write in an item grade color such as Mythic, you can simply use Insert > Template and search for Grade.

To choose a color simply select the desired grade in the dropdown and input your text in the box below that.

In case you should prefer Source editing, just use {{Grade|<Grade>|<Text>}}. Here a preview of all Versions with their Source Text.

How to add an Item

To write in an item to your text with a grade to it such as Hay Bale × 50, you can simply use Insert > Template and search for Item.

To choose an item simply select the desired item in the dropdown, select your grade in the dropdown below that and as an extra option, you can choose a quantity for it by selecting the setting in the left side of the template and typing the desired number into the input field. (Currently Only Hay Bales exist, more tba in future).

In case you should prefer Source editing, just use {{Item|<Item Name>|<Grade>|<Quantity>}}. Here a preview of all Versions with their Source Text.

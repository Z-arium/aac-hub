User Interface

Static Infobars

Upper Left - Character Statistics

This is a static info bar located at the upper left side of the in-game window. The top row lists the character level, character name, and active combat skills. If the character has unread mail, an envelope icon will be displayed. The next two rows are the green Health bar and the blue Mana bar, which show the total and current amounts for these attributes. The next row(s) of icons are any effects or conditions (Buffs) that are active. If the character has no active buffs, there is nothing displayed below the mana bar. Moving the mouse cursor over the area displays a window that lists the following: Occupation, Health, Mana, Equipment Points, Leadership, PvP Honor, and Hostile Faction Kills

Upper Right - Location Hotbar & Mini Map

This static info bar allows the player to view information about his current location (Region). The top row of icons, from left to right are: frame rate (if enabled). map size (S, M, L), markers and map settings. The player can place temporary markers on the Mini Map. If the player is in a Raid or a Party, only the leader can place these markers. The markers are temporary and disappear if the player changes region or logs out. The settings button (cog wheel) allows you to select if the Mini Map is displayed and if icons are displayed on it. These icons are the ones that you select on the Main Map, located in the lower right of the UI. The colored bar shows the time of day as a graphic, if the cursor is moved over the bar, the current Server Time will be displayed. The Region name. and any important status effects regarding the Region are displayed in this area. this displays what faction controls the area (if any), if it is in war or conflict and the time that status is in effect.

Lower Left - Divine Clock - Labor - Loyalty & Experience

This is a static display of the Divine Clock or AAC Patron Clock. for rewards the can be redeemed for time spent in game. These timers do not progress while the player is logged out. The count down resumes when the player returns to the game.

This static info bar shows the current percentage of experience that the player has gained towards the next level, the amount of labor points currently remaining and the amount of Loyalty Tokens the player has in his <<BAG>> (confirm this info)


Lower Right - Auction House - Daily Schedule - Marketplace

The Auction House is a player driven marketplace for buying and selling of items.

The Daily Schedule has the following tabs: Login Tracker, Daily Quests, Details, and Events

The Marketplace contains items that are available for purchase with Credits, Loyalty Tokens or Gilda Stars


In Game Menu - Lower Right

From left to right, the items are as follows: Character, Bag, Quest Log, Achievements, Skills Window, Map, Vocation, Community, Ranking Information, Menu.

Each item has a link for more detailed information.


Movable Infobars

Target

This is a static info bar that only appears when the character has selected or targeted an item in world. Some menu items, such as "Follow", are only available from this info bar. It appears in the middle of the upper screen.

Chat Window

This is a resizable, movable window that displays conversation or game alerts. A more detailed description can be found under the entry about in game chat and messaging.

Quest Menu

This is a resizable, movable window that displays active quests. Only the quests that the player has selected to be visible will show up here. More detailed information can be found under the entry about the Quest Log.

Skills Hotbar(s)

Skill hotbar, mount hot bar, fishing hot bar. A more detailed explanation of this area is found on the page about hotkeys and skills. (edit this info)

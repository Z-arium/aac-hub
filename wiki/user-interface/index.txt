<h3 id="Static_Infobars">Static Infobars</h3>
<figure><img src="/aac-hub/wiki-files/73/7311926b7afab7b03f75cb24f8c2f4a6ad5c8f37.jpg" width="592" height="121" loading="lazy"><figcaption></figcaption></figure>
<h4 id="Upper_Left_-_Character_Statistics">Upper Left - Character Statistics</h4><p>
This is a static info bar located at the upper left side of the in-game window. The top row lists the character level, character name, and active combat skills. If the character has unread mail, an envelope icon will be displayed. The next two rows are the green Health bar and the blue Mana bar, which show the total and current amounts for these attributes. The next row(s) of icons are any effects or conditions (<a href="/aac-hub/wiki/buffs-potions">Buffs</a>) that are active. If the character has no active buffs, there is nothing displayed below the mana bar. Moving the mouse cursor over the area displays a window that lists the following: <a href="https://wiki.aa-classic.com/index.php?title=Occupation&action=edit&redlink=1" rel="noopener">Occupation</a>, <a href="https://wiki.aa-classic.com/index.php?title=Health&action=edit&redlink=1" rel="noopener">Health</a>, <a href="https://wiki.aa-classic.com/index.php?title=Mana&action=edit&redlink=1" rel="noopener">Mana</a>, <a href="https://wiki.aa-classic.com/index.php?title=Equipment_Points&action=edit&redlink=1" rel="noopener">Equipment Points</a>, <a href="/aac-hub/wiki/leadership">Leadership</a>, <a href="https://wiki.aa-classic.com/index.php?title=PvP_Honor&action=edit&redlink=1" rel="noopener">PvP Honor</a>, and <a href="https://wiki.aa-classic.com/index.php?title=Hostile_Faction_Kills&action=edit&redlink=1" rel="noopener">Hostile Faction Kills</a></p><figure><img src="/aac-hub/wiki-files/73/7311926b7afab7b03f75cb24f8c2f4a6ad5c8f37.jpg" width="592" height="121" loading="lazy"><figcaption></figcaption></figure>
<h4 id="Upper_Right_-_Location_Hotbar_&amp;_Mini_Map"><span></span>Upper Right - Location Hotbar &amp; Mini Map</h4>
<p>This static info bar allows the player to view information about his current location (<a href="https://wiki.aa-classic.com/index.php?title=Region&action=edit&redlink=1" rel="noopener">Region</a>). The top row of icons, from left to right are: frame rate (if enabled). map size (S, M, L), markers and map settings. The player can place temporary markers on the <a href="https://wiki.aa-classic.com/index.php?title=Mini_Map&action=edit&redlink=1" rel="noopener">Mini Map</a>. If the player is in a Raid or a Party, only the leader can place these markers. The markers are temporary and disappear if the player changes region or logs out. The settings button (cog wheel) allows you to select if the Mini Map is displayed and if icons are displayed on it. These icons are the ones that you select on the Main Map, located in the lower right of the UI. The colored bar shows the time of day as a graphic, if the cursor is moved over the bar, the current <a href="https://wiki.aa-classic.com/index.php?title=Server_Time&action=edit&redlink=1" rel="noopener">Server Time</a> will be displayed. The Region name. and any important status effects regarding the Region are displayed in this area. this displays what faction controls the area (if any), if it is in war or conflict and the time that status is in effect.
</p>
<figure><img src="/aac-hub/wiki-files/73/7311926b7afab7b03f75cb24f8c2f4a6ad5c8f37.jpg" width="592" height="121" loading="lazy"><figcaption></figcaption></figure>
<h4 id="Lower_Left_-_Divine_Clock_-_Labor_-_Loyalty_&amp;_Experience"><span></span>Lower Left - Divine Clock - Labor - Loyalty &amp; Experience</h4>
<p>This is a static display of the <a href="https://wiki.aa-classic.com/index.php?title=Patron_Clock&action=edit&redlink=1" rel="noopener">Divine Clock</a> or AAC <a href="https://wiki.aa-classic.com/index.php?title=Patron_Clock&action=edit&redlink=1" rel="noopener">Patron Clock</a>. for rewards the can be redeemed for time spent in game. These timers do not progress while the player is logged out. The count down resumes when the player returns to the game.
</p><p>This static info bar shows the current percentage of experience that the player has gained towards the next level, the amount of labor points currently remaining and the amount of <a href="/aac-hub/wiki/currencies">Loyalty Tokens</a> the player has in his &lt;&lt;BAG&gt;&gt; (confirm this info)
</p>

<p><br>

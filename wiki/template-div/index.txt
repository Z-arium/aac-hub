Puts everything you give it next to each other in a row. When there is no more room the boxes continue on the next row. Any number of boxes works, there is no limit.

'''Usage'''
<pre>{{Div|em=0.5|first box|second box|third box}}</pre>

Is the same as
<pre><div style="display:flex; gap:0.5em; flex-wrap:wrap;">
<div>first box</div><div>second box</div><div>third box</div>
</div></pre>

* Every unnamed parameter becomes one box, in the order you write them.
* em (optional): the space between the boxes, in em. The default is 0.5.
* Empty parameters are skipped.

'''Example'''
<pre>{{Div|em=1|{{Mount|9002249}}|{{Mount|9002253}}|{{Mount|9002257}}}}</pre>

'''Good to know'''
* A parameter that contains an equals sign directly in the text (for example <code>style="color:red"</code> in plain HTML) is read as a named parameter and disappears. Write the number in front: <code><nowiki>{{Div|1=<span style="color:red">text</span>|2=second}}</nowiki></code>. Templates such as <code><nowiki>{{Mount|9002335|float=right}}</nowiki></code> are fine without numbers.
* Needs <code>Module:Div</code>.
